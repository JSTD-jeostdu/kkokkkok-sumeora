# 이어달리기 체인 CTA 강화 — 설계

## 배경
결과 화면(`#playend-panel`)에는 이미 "나도 숨기기" 버튼(`btn-play-make`)이 있어 클리어 후 바로 새 스테이지 제작으로 넘어갈 수 있다. 이 기능은 앱의 바이럴 성장 루프(플레이어 → 제작자 전환)의 핵심이지만, 현재는 "결과 카드 공유" 버튼과 같은 크기·같은 톤으로 나란히 놓여 있어 시각적으로 경쟁하고 있다. 이번 작업은 이 전환 지점의 전환율(CTA 클릭률)을 높이는 UX 개선이다.

## 범위
- `#playend-panel`(결과 화면)의 버튼 레이아웃·문구·스타일 변경
- 순수 HTML/CSS 변경. 기존 JS 클릭 핸들러(`btn-play-make`, `btn-share-card` 등)는 그대로 유지, id도 변경하지 않음
- Firestore 데이터 모델, 다른 화면, 게임 로직에는 영향 없음

## 변경 사항

### 1. 시각적 우선순위 재조정
- `나도 숨기기`: 단독 primary 와이드 버튼으로 격상. 홈 화면의 "숨기러 가기" 버튼과 동급 크기(`font-size:24px` 내외)
- `결과 카드 공유`: 큰 버튼(`.btn`)에서 작은 링크 스타일(`.link-btn`, 기존 "스테이지 삭제"와 동일 톤)로 격하, 하단으로 이동

### 2. 유도 문구 추가
`나도 숨기기` 버튼 바로 위에 도발적·장난스러운 톤의 한 줄 문구 추가:

> 이번엔 당신 차례예요. 친구를 제대로 골탕먹여보세요 😏

### 3. 최종 레이아웃 순서
1. 등급 뱃지 / 결과 시간 (기존 유지)
2. 유도 문구 (신규)
3. **나도 숨기기** (primary, 와이드, 강조) (신규 위치)
4. 홈으로 (`.btn-ghost`, 기존 유지)
5. 결과 카드 공유 + 스테이지 삭제 (작은 링크 2개, 하단) (신규 위치·스타일)

### 4. 시각 강조 애니메이션
`나도 숨기기` 버튼에 은은한 펄스 애니메이션 추가 — box-shadow가 포인트 레드(`--accent`) 톤으로 부드럽게 커졌다 작아지는 루프. 기존 `#timerbar`의 `barPulse` 키프레임과 같은 패턴(opacity 대신 box-shadow 강도를 사용)으로 통일감 유지.

```css
.relay-cta{ animation:relayPulse 2.2s ease-in-out infinite; }
@keyframes relayPulse{
  0%,100%{ box-shadow:var(--shadow); }
  50%{ box-shadow:0 4px 22px rgba(228,91,91,.45); }
}
```

전역 `@media (prefers-reduced-motion: reduce)` 규칙(`index.html` 기존 코드)이 모든 `animation`을 `.01ms`로 무력화하므로, 이 애니메이션도 별도 처리 없이 접근성 요구사항을 만족한다.

## 영향받지 않는 것
- `btn-play-make` 클릭 시 동작(스테이지 초기화 → 업로드 화면 이동)은 변경 없음
- `btn-share-card`(공유 카드 생성 로직), `btn-open-delete-play`(삭제) 기능은 스타일만 바뀌고 동작은 동일
- Firestore 문서 구조, 다른 화면(홈/제작/제작자 결과 보기) 영향 없음
